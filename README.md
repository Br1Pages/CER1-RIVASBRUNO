# CER1 - Centro Cultural Puerto Abierto

Front End del sitio web del Centro Cultural Puerto Abierto.
Certamen N°1 - EIN082B Taller de Lenguaje de Programación, UTFSM.

Bruno Rivas Vidal

## Tecnologías

- HTML5 con etiquetas semánticas
- CSS3 en hoja de estilos externa propia
- Bootstrap 5.3 (CDN): sistema de grilla, navbar, cards, formularios
- Google Fonts: Barlow y Barlow Condensed

## Estructura

```
CER1-RIVASBRUNO/
├── index.html          Página principal
├── cartelera.html      Cartelera de actividades
├── inscripcion.html    Formulario de inscripción
├── css/
│   └── estilos.css     Hoja de estilos propia
└── img/                Imágenes de las actividades
```

## Cómo verlo

Abrir `index.html` en el navegador. No requiere servidor ni instalación.
